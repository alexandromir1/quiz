# QuizLive

Площадка для живых викторин: создатель загружает изображения и придумывает 4 варианта ответа, игроки заходят со своих телефонов по коду комнаты. Баллы зависят от правильности и скорости ответа.

## Как играет

1. **Создатель** собирает викторину (`/create`) — картинка + 4 ответа на каждый вопрос.
2. Открывает **лобби** — появляется код комнаты.
3. **Игроки** заходят на `/join`, вводят код и имя.
4. Ведущий запускает вопросы; на экране телефона — картинка и кнопки ответов.
5. Чем быстрее правильный ответ, тем больше баллов (примерно 500–1000 за верный ответ).

## Локальный запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

Без внешних сервисов данные пишутся в папку `.data/` (подходит для разработки).

## Деплой на Vercel (обязательно Redis)

На Vercel **нельзя** писать в файловую систему, поэтому нужен Redis.

### Подключить хранилище (1–2 минуты)

1. Открой проект на [vercel.com](https://vercel.com) → **Storage**.
2. **Create Database** → выбери **Upstash Redis** (или **KV**).
3. Подтверди создание и привязку к проекту — переменные `UPSTASH_REDIS_*` или `KV_REST_API_*` появятся сами.
4. **Deployments** → на последнем деплое **Redeploy** (чтобы подтянуть env).

После этого сохранение викторин и живые комнаты заработают.
